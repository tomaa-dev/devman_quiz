# Боты-викторины (Telegram + VK)

Репозиторий содержит двух ботов-викторин — Telegram и ВКонтакте, которые задают пользователям вопросы из базы и проверяют ответы.
Состояние игры (текущий вопрос и счёт) хранится в Redis.


**Telegram-бот:** [@QuizzesTGBot](https://t.me/QuizzesTGBot)

**ВК-сообщество/бот:**[@VKBot](https://vk.ru/club243070653)

# Как установить
Операционная система: любая, где доступен Python 3 (Windows, macOS, Linux). Используем 'pip' для установки зависимостей (redis, python-telegram-bot, vk-api, python-dotenv):
```
pip install -r requirements.txt
```
Рекомендуется использовать virtualenv/env для изоляции проекта.

# Примеры запуска ботов (локально)

1) Telegram

```
python tg_bot.py
```

2) ВК

```
python vk_bot.py
```


# Переменные окружения
Программа использует нестандартные переменные окружения для настройки. Эти переменные не могут быть автоматически обнаружены и должны быть указаны в файле `.env` перед запуском программы.


**TG_BOT_TOKEN** - токен Telegram-бота.

**TG_CHAT_ID** — ID пользователя Telegram, которому бот будет присылать логи об ошибках.

**VK_TOKEN** — токен сообщества ВКонтакте.

**REDIS_HOST** — адрес базы данных Redis.

**REDIS_PORT** — порт базы данных Redis.

**REDIS_PASSWORD** — пароль для подключения к Redis.
